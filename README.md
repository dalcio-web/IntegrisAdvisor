# Integris Advisor

Landing page da Integris Advisor desenvolvida com Astro.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:4321`.

## Gerar a versão de produção

```bash
npm run build
```

Os arquivos finais serão gerados na pasta `dist`.

## HTML independente

Uma versão independente está disponível em `outputs/integris-advisor-landing-page.html`.
